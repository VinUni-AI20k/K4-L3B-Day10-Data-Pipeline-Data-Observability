# Nocturne — Gothic Data Observatory

Mở `index.html` trực tiếp bằng Chrome, Edge hoặc Firefox. Trang tự chứa CSS, JavaScript và họa tiết SVG, không cần cài thư viện hoặc kết nối mạng.

- Chọn Baseline, Corrupted, Repaired để xem metrics và quality tương ứng.
- Bấm **Chạy mô phỏng** để trình diễn chuỗi ba trạng thái.
- Bấm **Nguồn số liệu** để xem nguồn và giới hạn kết quả.
- Giao diện hỗ trợ màn hình điện thoại và bàn phím.

Đây là demo giao diện dùng số liệu snapshot đã lưu, không chạy pipeline, gọi API hoặc thay đổi ChromaDB. Nếu metrics được cập nhật, cần đồng bộ dữ liệu trong `index.html`. Chi tiết kiểm chứng nằm trong `report/group_report.md`.
